# Merix

AI-powered resume-to-job-description matching platform for Indian recruiters and campus placement teams.

## What is Merix?

Merix helps recruiters rank candidates against job descriptions with explainable, evidence-grounded match scores. Upload a JD and up to 100 resumes; get a ranked shortlist with per-skill evidence and DPDP-compliant data handling.
